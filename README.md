# Brclio Palm Universe · 掌心宇宙

GitHub 仓库：<https://github.com/Brclio/Brclio-Palm-Universe>。

参照用户提供的 `明晚胡彦斌将携TRA_20261017122234.mp4` 制作的手势互动网页，包含原片逐帧浏览与语音文字。首页默认进入完整鼠标流程，摄像头使用同一控制器；画面保持原片的16:9比例。

## 打开

需要 Node.js 20.11 或更新版本，无须安装 npm 依赖：

```sh
npm start
```

打开 <http://localhost:5173/>。逐帧分析在 <http://localhost:5173/analysis/index.html>。

## 按原片动作体验

1. 收拢四根长指握拳，拇指可以伸出，召出立体星星。松手后星星固定悬停。
2. 从左向右扫过星星，切换为太阳。把手收回左边，伸出拇指与食指，再向右扫过太阳，切换为月球。
3. 在月球旁以拇食指形成 C 形夹取，收窄开口使月球缩小，保持夹持移到右侧。
4. 伸直食指、张开拇指释放。月球放大并向右微移后固定；之后才将五指张开向左横扫，触发五个月相依次展开。
5. 回到最右端满月夹取，保持夹持向左上举起；再张开拇食指成 L 形。月球向手的左下放大，形成带唱臂的黑胶月球唱片。
6. 唱片固定悬浮。手移到唱片旁握拳，再张开五指使其爆散；点击「重来」重新开始。

点击「看原片动作」可循环观看当前步骤的原片片段。底部星星、太阳、月球、月相、唱片仅显示流程进度，不能点击或用数字键跳过动作。

鼠标操作中，按住对应收拢或夹持，松开对应张手；横向移动对应挥手，在球上按住拖动对应夹取搬动。页面提示随阶段变化。选择「开启摄像头」并允许浏览器访问后，直接使用上面的真实手势；模型在本地处理画面，不上传或录制。关闭摄像头后回到完整鼠标流程。

默认音乐为用户提供的 `茶花开了.m4a`（AAC、270秒）。进入页面、第一次操作、开启摄像头以及星星到月相阶段均不播放唱片歌曲，歌曲时间停在0。第一次点击或按键只静默解锁音频上下文；夹取满月、上举并松开，黑胶唱片显现时才从头自动播放。唱片音乐暂停时，唱片盘体与光环动效同步暂停；爆散时音乐淡出，重来或切换输入后停止并归零。主动暂停后继续移动/点击画布不会重新播放。音乐栏的 `↥` 可换成本地音频，唱片出现前换曲同样不会提前播放；文件只在当前标签页使用。永久替换修改 `index.html` 的 `#music` 音源。唱片出现后可用空格播放/暂停，`H` 隐藏界面控件。

操作音效默认开启：召星、两次挥手切换、夹取、释放、月相展开、再次夹取、唱片显现、爆散共9处短声，由相应动作成立触发一次。顶部「音效：开/关」只控制这些声音，唱片音乐有独立通道和按钮。重来、切换操作模式会停止旧音效；观看原片对照时暂停操作音效，关闭后不补播过去的动作。

`public/audio/sfx/` 的前7个短声来自原片对应时间窗，经过连续底声抑制与淡入淡出；源片是混合音轨，仍可能有底声残留。唱片形成与爆散两处按原片能量包络与宽频谱形状重建，避免把原曲或讲话混进新歌曲。不是无损独立音轨提取，也未完成听觉一致性审查。来源与处理方法见 `analysis/sfx-source-audit.md` 和素材清单；可用 `python3 analysis/build-interaction-sfx.py`（需要 NumPy、FFmpeg）重新生成。

摄像头默认开启镜像，模型关键点和视频画面使用同一次方向映射。手势左右以最终画面为准，向右扫过天体切换、张掌向左扫展开月相。顶部「镜像：开/关」同步翻转视频和骨架，并在摄像头模式重新开始流程，避免旧坐标误触；原片示范不额外翻转，鼠标操作不受镜像开关影响。

摄像头需要 localhost 或 HTTPS；请通过服务器打开，而非直接双击 HTML。部署时保留 `public/vendor/mediapipe` 目录和 WASM MIME 类型。服务器支持 MP4 与音频 Range 请求。

## 素材与实现

现行天体全部由代码建模并通过 Three.js / WebGL2 实时渲染，不加载原片截图、抠图、视频纹理或外部图片素材。`public/objects-3d.js` 共享一个渲染器，`public/models/` 保存可编辑模型、材质和着色器：

| 图形 | 当前实现 |
| --- | --- |
| 星星 | 封闭的圆润五角星曲面，真实前后厚度、金属材质、环境反射与缓慢转动 |
| 太阳 | 自转球体、流动等离子体、体积日冕，内缘奶黄至外缘橙金的渐隐光晕 |
| 月球 | 确定性代码生成月海、大小陨石坑、坑缘和放射纹；高程微位移、凹凸光照、连续自转及亮缘柔光 |
| 月相 | 五个自转球体共享月面材质，从右侧细月牙展开至满月；光照方向固定，柔光跟随亮侧 |
| 黑胶唱片 | 有厚度的沟槽盘体、嵌入月球、金属唱臂和唱头，实时流动光带；使用独立播放时钟 |

月面材质在初始化时由数学函数生成并缓存复用；它是美术化的程序地形，不是精确月球地理重建。程序生成材质和 Three.js 均不需要外网请求或 API Key。Three.js 0.186.1 已本地保存，许可证见 `public/vendor/three/LICENSE`。手部骨架、环境微粒和爆散仍由代码绘制，与三维场景合成。

月球约63秒自转一周，太阳约90秒一周；唱片中央月球以较慢速度随音乐转动，暂停歌曲时同步冻结。光晕使用实时球壳着色器，分别计算贴边柔光与外围散射，不会把月相暗面描成亮圈。修改前后与8秒自转对照见 `analysis/halo-rotation-comparison.png`。

`public/reference/` 中的旧截图、短片与 `public/reference-effects.js` 仅保留为旧版开发资料，不再被现行天体渲染器导入。旧 NASA 月面图片和生成脚本同样不参与当前画面。原视频只用于动作示范与分析；手姿关键点 JSON 只指导鼠标演练中的骨架姿态。操作短音效仍按上节说明保留已有来源，用户提供的《茶花开了》用于唱片音乐。

背景人物、房间和摄影光线由用户实际摄像头决定。代码模型是对参考风格的独立重建，不能保证与原片每个像素完全相同。实现与资源边界见 `analysis/procedural-3d.md`，模型正侧面查看 `analysis/procedural-model-angles.png`。

原占位配乐 `Lunar Reverie` 及生成脚本仅保留为历史资料；当前使用《茶花开了》。视频中的讲话和语音文字不参与手势控制、音频播放或网页时序。MediaPipe 资源全部本地保存，版本、上游许可和哈希见 `analysis/hand-tracking-notes.md` 与 vendor 目录。无须 API Key。

## 分析与验证

- `analysis/index.html`：全部1193帧的按需浏览器、原片同步、视觉事件与语音文字。
- `analysis/report.md`、`visual-timeline.json`、`source-reaudit-v2.md`：现行画面与动作分析。完整提取帧不代表人工逐张审阅所有帧。
- `analysis/transcript.json`、`.srt`、`.txt`：本地 Whisper 转录与自动时间码，使用原片字幕交叉确认，未人工逐音素校时。
- `analysis/interaction-contract.md`：当前控制器接口与动作响应。
- `analysis/pre-3d-validation/`：上一版视频纹理的浏览器报告与截图，仅作历史记录。
- `analysis/objects-3d-validation.json`：最终三维模型的几何深度、着色器、零图片/短片请求、转场及播放时钟专项验收。
- `analysis/revision-gesture-validation.json`、`revision-browser-validation.json`：本轮规则与浏览器验证；摄像头输入使用明确标注的测试替身。
- `analysis/source-gesture-replay.json`、`source-replay-controller-validation.json`、旧 `interaction-*-validation.json`：上一版历史记录，不能作为本轮原片回放全部通过的证据。原片已烘焙的特效遮住部分手指，旧重放存在漏检，未完成全流程。

运行 `npm run check` 检查语法，`npm test` 执行手势规则和音效生命周期验收。浏览器验证脚本为 `tests/revision-browser.cjs`，使用本机已有的 Playwright/Chrome 开发运行时。唱片音乐与操作音效的输出信号分通道测量，操作音效不会被误计为歌曲提前播放。

`tests/objects-3d-browser.cjs` 在实际 WebGL 渲染器上验证三维模型，并生成 `analysis/3d-final-*.png`；这些是独立渲染测试截图，完整交互截图为 `analysis/revision-*.png`。

这是对原片可见手型、操作顺序、图形与运动的重新实现。原始程序源码和识别参数未提供；截图或构造输入测试不能证明原算法完全一致。真人摄像头完整流程尚未实测，Safari及真实移动设备也未完成验证，因此不能声称识别手感和每个像素已100%一致。
