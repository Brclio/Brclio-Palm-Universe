# 程序三维重建

当前天体不再从参考视频提取素材。星星、太阳、月球、月相与唱片的几何、材质、光照、动画全部由代码生成，通过本地 Three.js 0.186.1 / WebGL2 实时绘制。

## 模块

- `public/models/sculpted.js`：有前后厚度的封闭五角星、实体黑胶沟槽、独立唱臂/唱头、流动光带。
- `public/models/celestial.js`：球面月球、实时光照月相、太阳表面的三维湍流和体积日冕。
- `public/models/lunar-surface.js`：固定种子生成整球月海与多尺度陨石坑，输出颜色和半浮点高程材质。纹理是启动时由代码计算的数值数组，不是载入的照片。生成后共享缓存，避免每帧重算地形。
- `public/objects-3d.js`：共享三维场景、正交相机、环境反射、灯光、模型池、透明度和动画时钟。
- `public/scene.js`：保留既有手势状态、原片的摆放位置、月相展开、夹取搬动、释放/唱片形成及爆散时序；把实际三维渲染结果与骨架/粒子叠合。

外观按原片关键帧逐项校准：星星使用人工量测的宽胖圆角轮廓、淡香槟色与柔和凹面；太阳偏黄白热区和短碎焰；月球暖奶灰、柔和月海；唱片为灰黑盘体及青绿流光。对照见 [原片与程序模型](procedural-style-comparison.png)。这张分析图的左栏才使用原片截图，右栏调用现行模型和场景绘制方法；截图不进入产品的天体素材路径。

立体性来自有深度坐标的几何、表面法线、灯光和观察角度，不是把图片贴在平面上。模型正侧面实际渲染见 [模型角度](procedural-model-angles.png)。

## 音频和时钟

歌曲和操作音效保留独立通道。页面输入只解锁音频上下文，模型准备完成且唱片实际显现后才激活《茶花开了》。唱片的 `recordClock` 仅在该阶段且歌曲播放中推进；暂停时盘体、月球微动和光带冻结，恢复时不跳过暂停时长，重来时内部时钟一起归零。太阳使用独立实时着色器时钟。

## 资源边界

现行天体渲染路径没有图片或视频纹理网络请求，没有 AI 生成位图，没有 NASA 月面图片。环境反射也由代码生成渐变和柔光，再计算预滤波环境贴图。Three.js 已本地保存；上游为 [Three.js](https://github.com/mrdoob/three.js)，遵循目录内 MIT LICENSE。

参考视频、旧截图/短片、旧 NASA 图片及旧生成脚本仍可作为历史分析资料保留。原片示范视频和 `hand-poses.json` 与运行中的图形模型分开使用；音乐和操作短音效的既有来源见 README 与音效审计，不属于本轮图形重建。

程序月面是按参考风格制作的艺术地形，并非真实地理测绘。星星形状、太阳噪声和唱片流光同样是独立算法实现；缺少原程序源码与材质，因此不能承诺逐像素一致。

## 验证

`tests/revision-browser.cjs` 检查主模型几何深度、WebGL 编译、运行时资源请求、实际太阳/唱片动画时钟、月相布局和完整交互/音频流程。`tests/record-audio-suspend-browser.cjs` 另测音频上下文中断后的暂停/恢复。结果写入当前验证报告；旧视频纹理版本的证据单独保留在 `pre-3d-validation/`。

最终模型专项为 `tests/objects-3d-browser.cjs`，结果见 [三维验证报告](objects-3d-validation.json)。它还检查太阳淡出期间继续流动、退出后停止；唱片中央月球的光照和微动同样随音乐暂停、恢复、重置。该测试使用明确标注的独立渲染场景，截图 `3d-final-*.png` 只作为图形证据。

鼠标流程通过浏览器实际事件操作。摄像头自动化使用明确标注的关键点替身，并非真人手势实测；真实移动设备和 Safari 尚未验证。
