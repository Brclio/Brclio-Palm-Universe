# 视频视觉与语音分析

原片：`明晚胡彦斌将携TRA_20261017122234.mp4`，1280×720，30 fps，39.786667秒，共1193个视频帧。

## 分析范围与精度

全部1193帧均已提取为640×360浏览副本，不代表人工逐张看过全部帧。人工核对采用2 fps全片总览、12–34秒的10 fps时序接触表、关键边界的30 fps连续帧，以及原生1280×720截图。第二次复核重点为召星拳形、扫球、初次松开、月相起点与黑胶唱片。详细像素证据见 `source-reaudit-v2.md`。

帧N的时间为 `(N−1)/30` 秒。淡入与运动模糊的视觉边界约有1–3帧误差，位置/尺寸为640×360分析帧上的近似值。原程序未提供源代码，因此手势阈值是重建建议，不能从画面证明原算法。

## 本轮复核的关键细节

- 星星有圆润的立体厚度、内凹面与金属明暗，原生491/500帧可清楚观察。原片太阳呈翻涌纹理，月面有明暗月海；现行网页用独立三维模型和程序材质重建这些视觉特征。
- 星→日、日→月都需手向右扫过物体附近；旧物向右退、新物从左补入，约0.4–0.5秒。第一扫开掌，第二扫可见拇指、食指伸出，不能规定两次都必须五指全张开。
- 初次释放是夹小后伸直食指、张开拇指，之后才逐渐张掌。小月球中心约从643帧的(531,259)平滑移到661帧的(550,259)，约0.6秒，恢复后直径约49px；不能锁在张开后的指间中心。
- 月相692帧(23.033秒)开始出现暗轮廓，693帧明确。左扫触发后自行展开，停手后仍继续。完整横排5个月相保持同一高度，右端满月固定。首暗月中心从695帧x≈488，经700帧x≈398、706帧x≈215，到727帧x≈93；初段并非立即高速冲到左端。
- 在右端满月旁夹取后向左上举，再将拇食指打开成L形，月球在手的左下方放大为唱片。唱片中心约(118,132)，外径约148px，中央月球约90px；顶部为唱臂转轴圆孔，唱臂向右下弯至唱头。
- 唱片放置后悬停。手在旁边先握拳再张开，32.967秒出现第一批粒子，33.000秒明显爆散；细尘延续约2秒。普通张掌、单纯抬指不能跳过流程。

## 当前网页素材与入口

首页保持16:9互动舞台，默认鼠标完整流程，摄像头共用同一状态机；「看原片动作」按当前步骤循环源视频片段。流程进度只读，不提供自由切换特效的快捷入口。

现行天体通过 `public/objects-3d.js` 与 `public/models/` 全部采用代码建模和 WebGL2 实时渲染。月面、太阳等离子体、黑胶沟槽和流光均为程序生成；不再使用视频帧或短片作为效果材质。`public/reference/` 与旧 `reference-effects.js`、NASA 图片只保留作历史开发资料。详见 [程序三维实现](procedural-3d.md)。

唱片音乐按照用户的补充要求绑定到显现：《茶花开了》在前面的手势阶段保持静音且时间为0，唱片出现才从头自动播放。首次可信输入仅静默解锁音频环境。唱片暂停时盘面动效停止，爆散时音乐淡出，重来停止并归零。

随后新增独立操作音效：9个动作事件分别触发短声，前7处为源片对应窗口经底声抑制后的片段，唱片形成与爆散两处为源片能量包络/宽频谱形状引导的噪声重建。该处理不能称为无损效果声分离，尚未进行听觉一致性审查。见 `sfx-source-audit.md`、`sfx/asset-validation.json` 和 `public/audio/sfx/manifest.json`。新浏览器报告将歌曲与音效分通道验收；旧 `record-audio-validation.json` 记录当时尚无操作音效的版本，不代表当前整页在所有前置动作时无声。

- `source-gesture-replay.json`、`source-replay-controller-validation.json` 与旧 `interaction-*-validation.json`：上一版历史记录，不能作为本轮原片模型回放完成的证明。

真人摄像头完整操作尚未实际验证。源视频上的烘焙特效会遮挡手，旧模型回放存在漏检；构造输入通过只证明控制规则，截图只证明该帧外观，均不能单独证明原算法或全部手感完全一致。
