# 操作音效源片复核

日期：2026-10-17。源文件：`明晚胡彦斌将携TRA_20261017122234.mp4`。

## 结论及证据边界

原片在星星召出、两次横扫、月球夹取/释放、月相展开和唱片出现附近都有可测量的音频变化，可作为操作音效的时间和包络参考。它们应由操作状态触发，不能把原片中段音轨连续循环播放，也不能提前启动唱片歌曲。

**本复核没有实际听取音频。** 当前模型的音频输入不受支持，以下是波形、频谱及已复核视觉事件的对照，不能据此声称某段听起来一定是“叮”“风声”或已完全去除原曲。

原片仅提供一条混合的 AAC 立体声音轨（48 kHz，2 声道），没有独立效果声分轨。14–26 秒即使没有台词，仍一直存在低中频有调底声，不能把“无台词窗口”等同于“纯音效窗口”。后半段唱片出现后还存在歌曲混入风险。仅裁切、均衡、高通或声道相减均不能证明无损分离。

## 检查方法

- 只读解码音轨为 24 kHz 双声道浮点 PCM；没有改动源视频。
- 在双声道平均信号上作 2048 点 Hann STFT、240 点步长，即 85.3 ms 窗宽、10 ms 步进。下表的谱通量峰值是窗口中心，实际起音允许约 ±43 ms，不能宣称 10 ms 的源事件精度。
- 计算每 100 ms 双声道 RMS、正向对数谱通量与四段频谱能量比（0–200、200–1500、1500–6000、6000–12000 Hz）。
- 视觉时间来自 `source-reaudit-v2.md` 与 `visual-timeline.json`；音效可能先于图形清晰成形。网页须把短声音的起点绑定动作成立，不是照原视频绝对时间播放。

## 对净化与验收的建议

1. 不使用14–34秒长音轨作为网页背景音乐。当前音乐仍只能在唱片实际可见时启动。
2. 前段可提取短候选，在邻近非动作窗口估计连续频谱底声并做温和抑制，但需要记录为“源片音效净化”，不能标注“无损提取独立音效”。
3. 声道相减没有通用隔离效果：14–15.5秒基线左右相关约.008；召星窗口约−.275；扫星约.450；唱片形成约.798。很多声效和底声都分布在立体声空间，直接转side会破坏部分效果；直接转mid也会保留歌曲。
4. 原片爆散窗mid RMS约−26.8 dBFS、side约−40.6 dBFS，左右相关约.92。中心消除会一起大幅删去该窗主信号，不能当作可靠“去人声/去歌曲”。
5. 音效应使用独立于唱片歌曲的增益和开关：用户可以静音操作反馈，同时保留唱片音乐。暂停唱片不应导致之前未发生的操作声补播。
6. 所有音效只在状态跃迁或明确的一次性缩小阈值成立时触发；重来、切换模式、丢失手势不能堆积迟发声音。首次真实点击只解锁音频上下文，不能因此播放任意效果或歌曲。
7. 默认音效音量宜低于唱片歌曲，输出加限幅/留余量；混合后检查峰值、边界点击、连续触发时节点清理。最终“与原片听感一致”仍需能实际听取音频的人审查。
